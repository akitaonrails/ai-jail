# v3.7.0

Default filtered-egress support for Antigravity (`agy` / `antigravity-cli`),
plus fixes for macOS `pbcopy` under `--macos-pasteboard`, read-only project
filesystems, and NixOS test builds.

Backward compatible: existing launches and saved policies keep their prior
behavior, and deny-by-default egress filtering is preserved.

## Added

- **Default filtered-egress API hosts for Antigravity (`agy` /
  `antigravity-cli`, PR #256).** Added `antigravity` to `KNOWN_API_AGENTS`,
  consolidated `command::api_hosts` and `onboarding::api_hosts` into one
  source of truth, and default-allowed Antigravity's functional API and OAuth
  hosts (`daily-cloudcode-pa.googleapis.com`, `cloudcode-pa.googleapis.com`,
  `aicode.googleapis.com`, `www.googleapis.com`, and `oauth2.googleapis.com`)
  when the network posture is unset. Telemetry (`play.googleapis.com`) and
  avatar (`lh3.googleusercontent.com`) endpoints stay excluded. Thanks
  @leonardovrezende.

## Fixed

- **macOS `pbcopy` under `--macos-pasteboard` (#257, PR #262).** Allowed
  `(allow mach-lookup (global-name "com.apple.lsd.mapdb"))` alongside
  `com.apple.pasteboard.1` so `pbcopy` can resolve LaunchServices UTI mappings
  instead of clearing the host clipboard. Still off by default and dropped
  under `--lockdown`. Thanks @edmarr for reporting the sandbox denial.

- **Launching from a read-only project filesystem (#260, PR #261).** When a
  trusted project profile exists and the project directory is on a read-only
  filesystem (`EROFS`), skip creating the empty legacy `.ai-jail` placeholder
  and warn via `security_warn` rather than aborting the launch, while keeping
  the mask if `.ai-jail` already exists (including as a symlink). Thanks
  @wtf9880.

- **NixOS test suite compatibility (#258, PR #259).** Added
  `require_lockdown_tools!("bash")` to the two remaining lockdown rlimit tests,
  recovered poisoned `SANDBOX_RUN_LOCK` guards in `tests/common/mod.rs`, and
  updated `flake.lock`. Thanks @wtf9880.

See the [security model](../docs/SECURITY.md) for what each grant exposes.
