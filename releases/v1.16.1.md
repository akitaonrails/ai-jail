# v1.16.1

## Fix DNS resolution inside Fedora toolbox

Inside a Fedora toolbox container, `/etc/resolv.conf` is a symlink to a path
under `/run/host/...` that itself chains to the systemd-resolved stub.
ai-jail was mounting the generated resolv file only at the canonical target,
so the inherited `/etc/resolv.conf` symlink dangled inside the sandbox and DNS
resolution failed (issue #91).

### Fixed

- When `/etc/resolv.conf` is a symlink, ai-jail now mounts the generated
  resolv file at the canonical target **and** directly at `/etc/resolv.conf`,
  so DNS works even when intermediate symlinks are lost inside the sandbox.

### Validation

- Added `resolv_symlink_also_mounted_at_etc_resolv_conf` to prove the toolbox
  case emits both binds.
- Added `resolv_regular_file_does_not_double_mount` to ensure no duplicate
  bind when `/etc/resolv.conf` is already a regular file.
